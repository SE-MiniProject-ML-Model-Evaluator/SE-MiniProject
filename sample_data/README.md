# Sample datasets for demos and tests

| File | Rows × cols | Task | Target | Notes |
|---|---|---|---|---|
| `iris.csv` | 150 × 5 | Classification | `species` | Classic 3-class flower dataset (TC-04, TC-07) |
| `iris_missing.csv` | 150 × 5 | Classification | `species` | Same, with 16 blank cells, to demo missing-value handling (TC-06) |
| `diabetes.csv` | 442 × 11 | Regression | `disease_progression` | scikit-learn diabetes dataset (TC-08) |

All three come from scikit-learn's bundled public datasets.
